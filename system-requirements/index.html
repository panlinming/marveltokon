Crossplay & Netcode

  • Full PS5 ↔ PC crossplay is supported at launch.
  • Matchmaking can be set to All (both platforms) or Same Platform Only in the online settings.
  • The game uses rollback netcode for online matches.
  • Launch window note: PC players reported performance and rollback issues in the first days; the developers have been improving stability through patches.
  • The online lobby hub supports up to 64 players.

Controllers & Keybinds

  • PS5 DualSense is the reference controller (default layout below).
  • Keyboard is fully supported on PC.
  • Arcade sticks and leverless controllers are supported.
  • Buttons can be remapped in character select, the pause menu or options.
